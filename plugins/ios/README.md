# Plugin demo for iOS

A small SwiftUI app that shows the in-tree plugin layers on a map. It is separate from the SDK's test apps in
`platform/ios`.

| Demo | Layer | What it shows |
|---|---|---|
| N-gons | [`ngon`](../ngon-layer) | Regular polygons from point features. Corners, color, stroke, blur and opacity come from feature properties; the sliders change paint properties at runtime. |
| 3D models | [`gltf`](../gltf-layer) | Cars, trees and a user puck drawn from `.glb` files. A feature picks its model with `model-id`; heading and size are paint properties; buildings hide the cars through `model-occlusion`. |

Both layer types only exist in a build with plugin support, and the `gltf` layer only has a Metal shader, so the app
only builds with `--//:renderer=metal --//:plugins=true`.

## Run it in the simulator

```sh
bazel build //plugins/ios:PluginDemo --//:renderer=metal --//:plugins=true --ios_multi_cpus=sim_arm64

# Boot a simulator, install the app and launch it.
xcrun simctl boot "iPhone 17 Pro" 2>/dev/null; open -a Simulator
rm -rf /tmp/PluginDemo && unzip -oq bazel-bin/plugins/ios/PluginDemo.ipa -d /tmp/PluginDemo
BUNDLE_ID=$(defaults read /tmp/PluginDemo/Payload/PluginDemo.app/Info CFBundleIdentifier)
xcrun simctl uninstall booted "$BUNDLE_ID" 2>/dev/null  # an install over the old build can keep the old binary
xcrun simctl install booted /tmp/PluginDemo/Payload/PluginDemo.app
xcrun simctl launch booted "$BUNDLE_ID"
```

The app opens on a list of demos. Launch it with `-demo models` or `-demo ngons` to open one straight away.

To show another plugin, write a view for it and add an entry to `Demo.all` in `Sources/DemoList.swift`.

## How the plugins get in

- The SDK links the `gltf` layer; `MLNPuckPlugin.register()` registers it.
- The `ngon` layer is not part of the SDK. The app links `//plugins/ngon-layer` and registers it with
  `NgonPlugin.register()` (`Registration/`), which calls the plugin's C entry point.
- Both have to be registered before a style that names them loads: a style naming an unregistered layer type drops
  the layer.
- Plugin layers have no Objective-C class, so the app adds them from JSON with
  `MLNStyle.addLayer(withJSON:belowLayerWithIdentifier:)` and changes them with
  `MLNStyle.setProperty(_:value:forLayerWithIdentifier:)`.

## Models

`Models/*.glb` are generated by `tools/generate_models.py` (no dependencies besides Python 3): a few low-poly cars,
a tree and a navigation arrow. The `gltf` layer only reads material base colors, so every part is a flat-colored
primitive. Models face +Z, and one mesh unit is one meter (one point for the puck, which uses `model-screen-scale`).
Run the script again after changing it:

```sh
python3 plugins/ios/tools/generate_models.py
```
