# Demo assets

Files the demo apps share, bundled at the root of an app:

- `styles/`: styles for demos that draw their own layers (`models.json`, `ngons.json`). They contain the plugin layers
  and declare their GeoJSON sources empty; the app puts the geometry into those sources once the style has loaded.
- `models/`: the `.glb` models of the `gltf` layer demo. They are generated by `generate_models.py` (Python 3, no
  dependencies): a few low-poly cars and a tree. The `gltf` layer only reads material base colors, so every part is a
  flat-colored primitive. Models face +Z, and one mesh unit is one meter. Run the script again after changing it:

  ```sh
  python3 plugins/demo/assets/generate_models.py
  ```

The demo of a plugin that only needs a style and a camera has no files here: it is described by the `demo` of the
plugin's `plugin.json`, and the generator copies it into the plugin's wrapper.
